# Treasury Bond PCA: AR and VAR Analysis

This repository contains R Markdown code and reports for time-series analysis of Treasury bond PCA-based series, focusing on the first and second principal components (PC1 and PC2) using autoregressive (AR) and vector autoregressive (VAR) models.

## Running the Code

Open the `.Rmd` files in RStudio. Use the input datasets specified in the code, install the required packages, and adjust file paths to match your local setup.
